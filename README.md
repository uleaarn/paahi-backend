# Paahi — A Voice That Understands

Paahi is a phone voice agent that serves several businesses. Each business has its own configuration, data, languages, workflows and notification contacts. Jalwa Modern Indian Dining (Montclair, NJ) is the first pilot business.

What exists today:
- **One workflow:** restaurant phone ordering (pickup). Other workflows aren't built yet, and nothing here claims they are.
- **Languages:** English (pilot). Spanish, French, Hindi and Telugu are wired end to end as **experimental**. See [docs/LANGUAGES.md](docs/LANGUAGES.md).
- **No n8n.** Calls, orders and staff email alerts all run in this backend.

## How a call works

1. Twilio calls `POST /twiml`. The **dialed number** picks the business (see `phone_numbers` in its `business.json`).
2. Twilio opens `WS /media-stream`, carrying the business ID and caller ID.
3. Caller audio goes to **Deepgram** (nova-3; multi-language mode if the business enables several languages). Pieces of a sentence are joined and the agent replies once the caller stops talking. Nothing the caller says is dropped.
4. The **model** (DeepSeek by default, any OpenAI-compatible API) reads what was said and calls tools. It never holds the order itself.
5. The **workflow** (`workflows/restaurant-ordering.js`) checks every change against that business's menu: real items, allowed sizes, modifiers and spice, quantities, and required fields.
6. The **readback is generated by code** in the call language. The order is sent only after the caller clearly says yes to the latest readback, and only once (idempotency key).
7. The order is **saved in Supabase Postgres** (row-level security keeps each business to its own rows). Only then does the caller hear "your order is in".
8. Staff are notified by email and/or webhook from an outbox, with retries. Delivery is tracked separately from the order.
9. If the save fails, the caller asks for a person, or the model fails twice, Paahi records a staff callback request and says so truthfully.
10. Replies are spoken in the call language: **Deepgram Aura** for English (same key as listening), Google Cloud TTS for the other languages. The caller can interrupt, and the call hangs up after the goodbye has played.

| File | Job |
|---|---|
| `server.js` | Twilio, Deepgram, TTS, audio playback, routes |
| `business-registry.js` | Loads and validates `businesses/*`, routes calls by dialed number |
| `call-factory.js` | Builds one call's conversation for one business |
| `conversation-engine.js` | One caller turn → model + tools → one reply; language switching; handoff |
| `workflows/` | Workflow modules (today: `restaurant-ordering`) |
| `order-state.js` | Order validation, readback, confirmation rules |
| `menu-service.js` | Menu lookup, sizes, modifiers, opening hours |
| `business-actions.js` | Saves orders, callbacks and call records for one business; notification outbox and retries |
| `database.js` | Postgres access; every transaction scoped to one business |
| `supabase/migrations/` | Schema and row-level security policies |
| `languages.js` | Language registry, voices, fixed phrases, "yes" detection |
| `businesses/<id>/` | Each business's `business.json` and data files |

## Setup

```bash
npm install
cp .env.example .env     # then fill in your own keys
```

Business settings go in `businesses/<id>/business.json`. See [docs/BUSINESSES.md](docs/BUSINESSES.md). Server-wide keys go in `.env`. Set up the database with [docs/DATABASE.md](docs/DATABASE.md).

## Try it without a phone

Type as the caller and talk to the same routing, workflow and conversation code the phone line uses. You only need the LLM key in `.env`:

```bash
npm run simulate
npm run simulate -- --languages en,hi,te    # try experimental languages
```

Type `/state` to see the call state and `/quit` to stop. Orders are saved to a local Postgres (PGlite) with the real schema, in `logs/simulator/db`. Nothing is emailed.

## Tests

```bash
npm run test:order   # routing, isolation, row-level security, languages, ordering, no duplicates
npm run test:menu
npm run test:analytics
npm test             # audio conversion
```

## Run with Twilio

```bash
npm run dev
ngrok http 3000
```

Set your Twilio number's voice webhook to `POST https://YOUR_DOMAIN/twiml`. Then either add that number to the business's `phone_numbers`, or set `DEFAULT_BUSINESS_ID`.
